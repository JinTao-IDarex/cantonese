# 粤语系统教程 · 广州话完全手册

写给定居广州的学习者：从声韵调起步，经词汇、语法，到十个生活场景与验收测验 —— 一套完整的广州话自修体系。

纯静态站点，无需构建，直接打开 `index.html` 或托管到任意静态服务器 / GitHub Pages 即可。

## 页面结构

| 页面 | 内容 |
|------|------|
| `index.html` | 首页总览 |
| `phonetics.html` | 声韵调（语音） |
| `vocabulary.html` | 词汇 |
| `grammar.html` | 语法 |
| `dialogues.html` | 情景对话 |
| `practice.html` | 验收测验 |
| `diff.html` | 粤普差异 |

内容数据位于 `assets/data-*.js`，样式与交互在 `assets/style.css` / `assets/app.js`。
